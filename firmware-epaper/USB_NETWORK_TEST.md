# 小米17U USB网卡测试

目标：不装手机App，运行时仅手机和板子，通过手机网络访问106。Mac仅编译、刷写和读日志。

## 已测与未测

- 小米17U开启USB网络共享后，USB为2717:ff88，包含RNDIS和ADB接口；AOA GET_PROTOCOL=2。
- 参考scrcpy的ID2/发送方式，鼠标注册、描述符与相对移动、注销请求成功，用户已看到指针。未安装App、未发送点击或文字，手机RNDIS模式保留。这是Mac作为USB主机的手机端协议测试，不能替代板子独立验收。
- 板子NCM网卡构建已刷入。Mac实际识别CDC和NCM控制/数据接口，PID4041、无HID，STATUS WiFi/HID/蓝牙=0、screen_error=0；已收发以太网数据。
- 手机是否识别NCM、以太网共享开关、板子DHCP获取地址、通过手机访问106、网络有流量时切换输入及停止，尚待逐项实测。

## 独立构建

在仓库根目录、ESP-IDF5.5.2环境下：

```
idf.py -C firmware-epaper -B build-usb-network -D SDKCONFIG=sdkconfig.usb-network -D 'SDKCONFIG_DEFAULTS=sdkconfig.defaults;sdkconfig.usb-network.defaults' build
```

稳定CDC构建仍为`idf.py -C firmware-epaper build`。两种构建、配置、含设备令牌的二进制都已忽略。原完整备份与NVS/assets保留。

## 手机配合

1. 手机从Mac断开，板子直接用数据线连接手机。手机为USB主机，板子为受电设备；电池可保持连接。
2. 接入后查看便携热点的“通过以太网共享”，或搜索“以太网”。这与手机作为USB设备时的“USB网络共享”是不同角色。
3. 开启以太网共享后，板子作为DHCP客户端，不提供DHCP服务器。屏幕进度为等待连接、等待共享IP、取得IP连接106、106已连接；取得IP后通过原有TLS和设备令牌访问106。
4. 默认WiFi/蓝牙/HID关闭。短按循环额度、交互、USB控制、网络状态；USB控制页显示完成后15秒内重新长按BOOT两秒并松开，才允许开启HID。物理拔插、停止和重启撤销权限。
5. 未看到以太网共享开关不算联网成功；记录手机是否识别网卡，不能以Mac识别网卡替代。

## 调试

`python3 tools/board_console.py status`包含net阶段、RX/TX计数，`logs`输出RAM日志。若电池保持连接，手机换回Mac可读取上次日志；若断电，RAM日志会清除。软件BOOTLOADER入口在稳定固件已验证返回原生下载口，刷写后watchdog_reset可启动，无须反复拆电池。

## 18:30 调试记录与界面修订

小米实际为25128PNA1C / Android17；USB调试已授权，设备由本机5038端口ADB服务持有（默认5037不可见）。只对指定小米设备操作；临时TCP5555用于手机直连板子时诊断，测试结束应对该设备执行adb usb关闭。手机省流量状态disabled；系统Ethernet已enabled，接口匹配(usb|eth)\d+，内核包含cdc_ncm、cdc_ether、r8152等驱动。直连板子时接口和共享尚待检查，不能把Mac侧DHCP地址归因手机。

本地页面新增日期时间（北京时间，SNTP未校时显示时间未同步），新增按键与语音帮助页。NCM共5页，CDC共4页；确认页授权行为不变。现有固件未实现录音上传，帮助页明确显示语音尚未接通，避免误导。小太阳短按翻页，普通页长按停止；控制页重新长按两秒并松开确认，电源键长按1.5秒释放电池电源锁存。

NCM修订版已刷入目标70:04:1D:DB:D4:18，写入hash校验成功，日志screen_error=0；软件重启后hid=0、wifi_enabled=0、bluetooth=0。CDC和NCM均构建通过，22项Python测试与两项C++测试通过。时间实际校准及手机独立联网仍需手机直连验收。

## 语音版本

现已实现独立语音输入页（NCM首页短按4次），按住小太阳键，准备约1秒后显示正在录音，再继续说话，松开发送；有效音频0.4至10秒。初始麦克风关闭，每次录音前RX重新开启并清队列、过滤启动瞬态，录完关闭。语音页短按翻页，其他普通页长按停止；控制页确认不变。拔USB取消当前录音与上传结果，重新联网后补发停止。

106 POST /voice已部署，设备令牌鉴权、320000字节上限，调用既有云端ASR并删除临时WAV；独立nginx路由允许400KB、90秒。使用启动会话和录音序号，停止先到/上传后到也不能覆盖停止状态。语音识别文字显示在交互页，识别不代表手机已执行。

真实合成测试语音“这是语音识别测试，请显示当前时间”由106准确识别，HTTP200耗时约0.8秒；这是服务器测试，未替代板子对手机网络的录音上传验收。目标实板重复MIC TEST为16000samples、RMS109.0/106.8，样本丢弃不保存不上传；语音页显示日志正常，软件重启仍hid/wifi_enabled/bluetooth=0。修订版两种固件构建、29项Python测试、独立审查通过。

mic-test命令可做1秒硬件采样诊断，仅输出RMS/peak。正常录音只能在本地语音页按住启动。手机USB以太网共享仍待直连诊断；当前没有完成屏幕采集和手机自动执行闭环。
